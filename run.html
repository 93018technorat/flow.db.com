Live PoC - cross-origin postMessage DOM-XSS on flow.db.com

Served from a foreign origin (GitHub Pages). It frames a real Deutsche Bank Livebook flipbook on flow.db.com and delivers a crafted book.xml via postMessage. The flipbook's window.onmessage has no origin check, so the XML's <node title> is rendered through jQuery .append() unescaped, executing script in the flow.db.com origin.
